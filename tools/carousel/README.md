# Карусели для инстаграма

Собирает пост из фотографий: кроп под формат, мягкая градиентная виньетка и
короткий текст, положенный на пустое место кадра — не на лицо и не на предметы.

Обычно этим управляет агент — скажите Claude «сделай карусель про …», и он
подберёт кадры, напишет текст и запустит рендер сам
(`.claude/skills/instagram-carousel/`). Ниже — как запускать руками.

## Запуск

```bash
npm install
node tools/carousel/render.mjs tools/carousel/examples/mir-vsegda-za.json
```

Результат — в `out/carousel/<слаг>/`: пронумерованные PNG, `caption.txt` с
подписью и `preview.html`, где вся карусель видна одной лентой.

Первый запуск на новой машине требует браузер для рендера:

```bash
npx playwright install chromium
```

### Флаги

| Флаг | Что делает |
|---|---|
| `--out <папка>` | куда складывать (по умолчанию `out/carousel`) |
| `--size 4:5` | холст: `4:5` (1080×1350), `1:1`, `9:16` |
| `--guides` | нарисовать выбранную рамку текста и обрезку до квадрата |
| `--jpg` | JPEG вместо PNG |

Instagram обрезает все слайды под пропорции первого, поэтому формат общий на
всю карусель и менять его в середине нельзя.

## Спека

```json
{
  "slug": "mir-vsegda-za",
  "size": "4:5",
  "handle": "@anastasypetrova",
  "grade": "none",
  "slides": [
    { "photo": "hero" },
    { "photo": "quote", "text": "Перестань думать, что мир против тебя." },
    { "photo": "about", "text": "…", "box": { "x": 0.09, "y": 0.14, "w": 0.44 } }
  ],
  "caption": "Текст поста."
}
```

| Поле слайда | Что |
|---|---|
| `photo` | имя слота (`hero`, `about`, `quote`, `club`, `telegram`, …) или путь к файлу |
| `text` | текст слайда. Без него слайд остаётся чистым фото |
| `size` | кегль: `s`, `m` (по умолчанию), `l` |
| `box` | закрепить место: доли кадра `{x, y, w}` от левого верхнего угла |
| `tone` | `light` — белый текст, `dark` — тёмный, `auto` — по яркости фона |
| `vignette` | сила виньетки; `0` выключает, по умолчанию считается по кадру |
| `focus` | кроп: `centre`, `north`, `south`, `auto` (по содержимому) |
| `grade` | тон: `none` (по умолчанию), `natural`, `warm`, `muted` |

В тексте работает `*курсив*`, `**акцент серифом**` и `//` — жёсткий перенос
строки.

## Как выбирается место для текста

`analyze.mjs` считает по кадру карту детализации (Собель) и ищет самый спокойный
прямоугольник: небо, стену, воду. К оценке добавлены три поправки — держаться
верхней трети, избегать пересвеченных участков под белым текстом и при прочих
равных предпочитать левую сторону. Это повторяет раскладку референсных каруселей.

Автоматика ошибается там, где пустое место есть, но оно смысловое — например,
стена прямо за головой. Тогда ставьте `box` руками; `--guides` показывает
выбранную рамку поверх слайда.

Виньетка тоже считается по кадру: тёмному фото достаётся почти ничего, светлому
— столько, чтобы белый текст держался. Смысл в том, чтобы это читалось как свет,
а не как серая плашка.

## Шрифт

Inter Regular из `src/fonts/`. В референсных каруселях — системный шрифт iOS;
Inter это тот же неогротеск и уже лежит в проекте, поэтому слайды выглядят
одинаково на любой машине и ничего не скачивается при рендере.
