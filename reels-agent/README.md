# Монтаж рилс

Сборка вертикальных Reels из сырого материала: нарезка, цветокор, субтитры,
стикеры-иллюстрации. На выходе готовый MP4 1080×1920, а не проект для доводки.

Все параметры лежат в [`preset.json`](./preset.json). Числа там сняты замерами с
референса, а не подобраны на глаз — как именно, написано ниже.

## Как это работает

```
ты                     →  ретушь лица в CapCut, экспорт мастера
агент (молча)          →  нарезка · цветокор · субтитры
агент → тебе           →  лист: сценарий с таймкодами + что предлагаю проиллюстрировать
ты → агенту            →  одна строка: «да» / «все кроме 4 и 9» / «7 — глобус»
агент                  →  финальный рендер
```

Согласование ровно одно. Всё, что можно решить безопасно, решается без вопросов.

## Почему ретушь осталась ручной

Единственный шаг, который не автоматизируется без потери качества. `ffmpeg`
умеет только сглаживание по всему кадру без детекции лица — это пластиковый
вид. Открытые модели (GFPGAN, CodeFormer) сделаны для реставрации убитых лиц,
а на хорошем исходнике переглаживают, слегка меняют черты и мерцают между
кадрами. Ретушь CapCut обучена именно под эту задачу и стабильна по времени.

Порядок важен: ретушь **до** субтитров и цветокора. Иначе модель пройдётся по
тексту.

## Нарезка: что решает код, а что человек

**Механически** (без согласования): паузы длиннее 700 мс подрезаются до 250,
изолированные слова-паразиты вырезаются, подряд идущие повторы схлопываются.
Правки локальные, смысл не трогают.

**Смыслово** (я читаю): выбор лучшего из нескольких дублей, отступления,
порядок мыслей. Дефолт осторожный — **при сомнении кусок остаётся**.

Точки реза всегда в тишине, никогда посреди слова, с воздухом ±100 мс.
Аудио на стыке — кроссфейд 40 мс, иначе щёлкает. Видео режется жёстко,
джамп-кат маскируется лёгким зумом 1.0 → 1.04.

## Стикеры и лицо

Размер **не фиксирован**: план бывает крупнее и мельче, свободная полоса от
этого меняется. Размер считается от реально доступного места.

Зона лица определяется детектором YuNet **по окну жизни конкретного стикера**,
а не по одному кадру и не по всему ролику. Причина: если считать по кадру,
через секунду стикер окажется на щеке; если по всему ролику — объединённая
зона накроет весь кадр и ставить будет некуда (проверено на референсе:
union-бокс вышел 0,0–720,1211).

Порядок попыток: боковая полоса → под лицом → над лицом → ужать до минимума.
Поверх лица не ставится никогда.

## Откуда взялись числа в пресете

## Грабли

**Модель whisper.** Нужна мультиязычная (`medium`, `large-v3`) плюс
`language: "ru"`. Модели с суффиксом `.en` — англо-только, на русском выдают
мусор молча, без ошибки. В примере из скилла `remotion-captions` стоит как раз
`medium.en`.

**sharp применяет `resize` раньше `composite`.** Если собираешь коллаж и сразу
ужимаешь — канва ужмётся до вклейки, и куски перестанут влезать. Клеить и
жать нужно двумя проходами.

**OpenCV 5 выкинул Haar-каскады.** `cv2.CascadeClassifier` больше нет,
вместо него `cv2.FaceDetectorYN` + модель `yunet.onnx`. Модель лежит в
opencv_zoo под git-lfs, с `raw.githubusercontent.com` приезжает указатель на
378 байт вместо файла — тянуть надо с `media.githubusercontent.com`.
