# Запуск на маке

Разово — минут пятнадцать. Дальше только кидать ролики в папку.

## 1. Забрать репозиторий

В **GitHub Desktop**: `File → Clone repository` → выбрать `anastasypetrova/website`
→ запомнить, куда он ляжет (обычно `Documents/GitHub/website`).

Ветка нужна `claude/wizardly-edison-20e8p4` — переключается в шапке GitHub Desktop,
выпадающий список `Current branch`.

## 2. Поставить Node

Скачать с [nodejs.org](https://nodejs.org) версию **LTS**, открыть `.pkg` и
пройти установщик. Терминал не нужен.

## 3. Поставить Claude Code

По инструкции с [claude.com/code](https://claude.com/code). Дальше все команды
выполняет он — тебе в терминал лезть не придётся.

## 4. Положить ролик

В Finder открыть папку репозитория → `reels-agent/input/` → перетащить туда
мастер после ретуши.

Файл останется у тебя: `input/`, `work/` и `output/` прописаны в `.gitignore`,
поэтому GitHub Desktop их не увидит и наружу они не уйдут. **Это намеренно** —
видео в git класть нельзя: GitHub режет файлы больше 100 МБ, а история хранит
все версии навсегда.

## 5. Сказать Claude Code

Открыть Claude Code в папке репозитория и написать:

> прогони ролик из reels-agent/input

Дальше он всё сделает сам. Если хочется руками, команды такие:

```bash
cd reels-agent
npm install          # разово
npm run doctor       # проверка, всё ли на месте
npm run probe        # что за файл принесли
npm run transcribe   # распознать речь (первый раз качает модель ~3 ГБ)
npm run plan         # план реза + лист согласования
```

## Что получится

`output/` — готовый ролик.

`work/report.md` — отчёт: сколько вырезано и почему. Читать необязательно,
он на случай, если результат чем-то не устроил и надо понять, где подкрутить.

## Если что-то пошло не так

`npm run doctor` показывает состояние окружения: версию Node, наличие ffmpeg,
скачана ли модель, сколько места на диске.

**Место.** Промежуточный ProRes занимает примерно 2.5 ГБ на минуту 1080×1920.
Это цена за то, что качество не теряется между стадиями. После рендера папку
`work/` можно чистить.

**Скорость.** Первый запуск дольше: качается и собирается whisper.cpp плюс
модель. Дальше только распознавание — на Apple Silicon примерно вдвое быстрее
реального времени.

**ffmpeg.** Приезжает пакетом при `npm install`, ставить отдельно не нужно.
Если на маке уже стоит свой через Homebrew — возьмётся он, он немного быстрее.
