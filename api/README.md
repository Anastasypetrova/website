# Бот и формы сайта

Бот делает три вещи:

1. **Принимает форму «Остались вопросы?»** — присылает сообщение вам в Telegram
   и сразу отвечает человеку на сайте, если вопрос совпал с разделом «Частые
   вопросы».
2. **Принимает подписку на рассылку** — присылает адрес вам в Telegram.
3. **Отвечает людям в Telegram** — показывает частые вопросы кнопками, отвечает
   на них сам, а незнакомый вопрос передаёт вам. Вы отвечаете **реплаем** на это
   сообщение, и бот пересылает ваш ответ автору вопроса.

Ответы берутся из `src/content.ts` — того же файла, из которого сайт рисует
раздел «Частые вопросы». Поправите ответ на сайте — бот начнёт отвечать
по-новому. Двух разных версий одного ответа не будет.

## Почему нужен отдельный сервис

Сайт статический и лежит на GitHub Pages. Всё, что попадает в страницу, может
прочитать любой посетитель — включая токен бота. С токеном бота можно писать от
вашего имени кому угодно. Поэтому токен живёт здесь, в Cloudflare Worker, а сайт
знает только адрес этого воркера.

Cloudflare Workers бесплатны до 100 000 запросов в день и не просят карту.

## Одно ограничение, которое не обходится

**Telegram-бот не может написать первым тому, кто никогда не открывал с ним чат.**
Это правило самого Telegram, защита от спама.

Поэтому: человек, заполнивший форму на сайте, получает ответ **письмом** — в
каждом уведомлении есть ссылка «Ответить письмом», нажимаете и пишете. А те, кто
пишет боту в Telegram, получают ответ прямо в Telegram.

## Установка — примерно 15 минут

### 1. Создать бота

В Telegram напишите **@BotFather** → `/newbot` → имя и username. Он выдаст
**токен** вида `7123456789:AAH...`. Сохраните.

### 2. Узнать свой chat id

Напишите своему боту любое сообщение, потом откройте в браузере:

```
https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
```

Найдите `"chat":{"id":123456789` — это число и есть ваш **chat id**.

### 3. Выложить воркер

Нужен бесплатный аккаунт на [dash.cloudflare.com](https://dash.cloudflare.com).

```bash
cd bot
npm install
npx wrangler login          # откроет браузер, разрешите доступ

npx wrangler secret put BOT_TOKEN        # вставьте токен из шага 1
npx wrangler secret put OWNER_CHAT_ID    # число из шага 2
npx wrangler secret put WEBHOOK_SECRET   # придумайте длинную строку, например из букв и цифр

npx wrangler deploy
```

В конце wrangler напечатает адрес вида
`https://samadhi-bot.ваш-логин.workers.dev` — **скопируйте его**.

### 4. Подключить бота к воркеру

Подставьте свои значения и откройте ссылку в браузере:

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=<АДРЕС_ВОРКЕРА>/telegram&secret_token=<WEBHOOK_SECRET>
```

Должно ответить `{"ok":true,...}`.

### 5. Включить формы на сайте

В файле `src/api.ts` впишите адрес воркера:

```ts
export const API_BASE = 'https://samadhi-bot.ваш-логин.workers.dev';
```

Закоммитьте и запушьте — сайт пересоберётся сам.

Пока эта строка пустая, формы не молчат: они открывают почтовую программу
посетителя с уже заполненным письмом на `hello@metasouls.co`. Ничего не теряется.

## Проверить, что всё работает

```bash
node bot/test.mjs      # 24 проверки логики, без сети и без токена
cd bot && npm run tail # живой лог воркера, когда он уже выложен
```

Вручную: напишите боту `/start` — должны прийти приветствие и кнопки с
вопросами. Заполните форму на сайте — сообщение должно прийти вам в Telegram.

## Если что-то не так

- **Форма отвечает «не получилось отправить»** — проверьте, что `ALLOWED_ORIGINS`
  в `wrangler.toml` совпадает с адресом сайта, и что `API_BASE` в `src/api.ts`
  указан без слэша на конце.
- **Бот молчит** — откройте
  `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo`, там будет причина в поле
  `last_error_message`.
- **Ваш ответ не доходит до человека** — отвечать нужно именно **реплаем** на
  сообщение бота, а не отдельным сообщением: метка автора вопроса живёт внутри
  того сообщения.
