# Anywhere Sauna — сайт

Премиальные финские сауны, Дубай. Статический сайт: один `index.html`, стили и
два скрипта. Собирать ничего не нужно — открой `index.html` в браузере или
выложи папку на любой хостинг (GitHub Pages, Netlify, Vercel, Cloudflare Pages).

## Что где

- `index.html` — вся страница. Сайт только на английском.
- `app.js` — мобильное меню, форма → WhatsApp, видео, анимации.
  В начале файла блок `CONFIG`: название, номер WhatsApp, Instagram, TikTok.
- `styles.css` — дизайн. Цвета и шрифт в `:root` наверху.
- `fonts/` — Inter 400–800 (латиница), лежит локально, к Google не ходим.
- `images/` — фотографии, см. `images/README.md`.
- `robots.txt`, `sitemap.xml` — для поисковиков, см. раздел ниже.
- `guides/` — восемь статей под поиск и страница со списком. Генерируются
  скриптом, в нём же лежат тексты (см. ниже).

## Что на сайте — выдумано и ждёт правки

- **Отзывы** (`#reviews`) — все три написаны мной как образец. Имена,
  районы и слова придуманы. Заменить на то, что действительно сказали

- **Наука** (`#science`) — общие тезисы про жар и тело. Фотографии на месте.
  Текст в трёх карточках мой: факты общеизвестные, формулировки мои.
- **Вопросы** (`#faq`) — цены, размеры, печи, электрика и гарантия взяты
  из брошюры дословно. Проверить стоит три вещи, которых в ней нет:
  время прогрева (написано «обычно 30–45 минут»), уход и формулировку
  про согласование с застройщиком.

## Перед запуском

1. Проверь тексты, которые я написала от себя: описания трёх саун, четыре шага
   в разделе «Как мы работаем» и ответы в FAQ. Факты в них из брошюры, но
   формулировки мои.
2. В `index.html` в тегах `og:*` поставь полный адрес сайта и картинки, когда
   появится домен. Относительные пути мессенджеры молча выкидывают.
3. Если бренд пишется иначе (например, с другим регистром) — поправь
   `CONFIG.brand` в `app.js`.
4. **TikTok.** В `CONFIG.tiktok` стоит то же имя, что у Instagram. Если
   аккаунт называется иначе, поправь, иначе иконка на обложке ведёт в никуда.

## Чтобы гугл нашёл сайт

Со стороны кода всё готово. На странице есть:

- `<title>` и описание под поиск, обрезанные по длине, которую гугл показывает;
- `rel="canonical"` — один правильный адрес страницы, без дублей;
- `robots.txt` и `sitemap.xml` (в карте сайта перечислены и фотографии —
  чтобы они попали в поиск по картинкам);
- разметка для гугла: кто мы, где работаем, телефон, соцсети и три цены
  (15 000 / 20 000 / 25 000 AED) — это то, из чего собираются расширенные
  сниппеты в выдаче;
- 16 вопросов с разметкой FAQ — гугл умеет раскрывать их прямо в результатах;
- у каждой фотографии прописан размер (страница не «прыгает» при загрузке),
  подпись `alt` и отложенная загрузка — это влияет на оценку скорости, а она
  влияет на позиции;
- превью для мессенджеров и соцсетей с абсолютными адресами.

**Чего я не стала делать намеренно:** разметки с рейтингом и отзывами. Отзывы
на сайте пока выдуманные (см. выше), а звёздочки из выдуманных отзывов — это
ровно то, за что гугл банит. Появятся настоящие — добавим.

- восемь статей в `guides/` под поисковые запросы, у каждой своя разметка
  статьи и «хлебных крошек», ссылка из подвала и перелинковка между собой;
- значки для телефона (`apple-touch-icon.png`, `icon-192/512.png`) и
  `site.webmanifest` — сайт можно положить на домашний экран;
- страница `404.html` в дизайне сайта, закрытая от индексации;
- обложка и шрифты загружаются с приоритетом (`preload`) — это первое, что
  меряет гугл при оценке скорости;
- `_headers` — кеширование: HTML не кешируется (правки видны сразу),
  картинки, шрифты и видео — на год.

## Счётчики трафика

В начале `app.js`, блок `CONFIG.analytics`. Три поля, все пустые:

```js
analytics: {
  ga4: '',         // Google Analytics → Админ → Потоки данных → G-XXXXXXXXXX
  metaPixel: '',   // Meta Events Manager → числовой Pixel ID
  tiktokPixel: '', // TikTok Events Manager → Pixel ID
},
```

Вписала id — счётчик заработал со следующей загрузки. Оставила пустым —
**не грузится вообще ничего**: ни скрипта, ни куки, ни одного запроса наружу.
Проверено: с пустыми полями сайт не обращается ни к одному чужому домену.

Считаются не только просмотры. Каждое нажатие на WhatsApp и отправка формы
шлют событие о заявке (`generate_lead` в Google, `Lead` в Meta, `SubmitForm`
в TikTok) — так в отчётах видно не «сколько зашло», а «сколько написало».

Счётчики работают и на страницах статей — туда как раз приходит трафик из
поиска.

Если среди посетителей будут европейцы, по их правилам нужен баннер согласия
на куки. В ОАЭ такого требования нет. Решать тебе; сделать можно за полчаса.

## Как выложить сайт на домен

Сайт — обычная папка с файлами, собирать нечего. Домен: `anywheresauna.shop`.

Я не могу сделать это за тебя: создавать репозитории мне GitHub не разрешает,
а до хостингов у меня нет доступа в сеть. Но всё подготовлено.

### Netlify (проще всего, бесплатно)

1. `netlify.com` → **Sign up** через GitHub.
2. **Add new site → Import an existing project → GitHub →** репозиторий
   `anastasypetrova/website`.
3. В настройках сборки:
   - **Branch:** `claude/focused-lamport-gznl3f`
   - **Base directory:** `sauna`
   - **Build command:** оставить пустым
   - **Publish directory:** `sauna`
4. **Deploy.** Через минуту сайт откроется на адресе вида `что-то.netlify.app`.
5. **Domain management → Add a domain →** `anywheresauna.shop`.
6. Netlify покажет, какие записи прописать у регистратора домена. Сделай
   ровно то, что он показывает — конкретные адреса у них меняются, поэтому
   я их здесь не пишу. Сертификат HTTPS выпустится сам.

Файл `netlify.toml` в этой папке Netlify прочитает сам: он знает, что
собирать нечего, и подключает страницу 404.

### Cloudflare Pages

То же самое, и даже проще, **если домен куплен в Cloudflare** — тогда DNS
пропишется автоматически. Настройки те же: сборки нет, корень — `sauna`.

### GitHub Pages — не советую

В этом репозитории уже настроен деплой другого сайта, а GitHub Pages даёт
один сайт на репозиторий. Если всё же хочешь — нужен отдельный репозиторий;
файл `CNAME` с доменом уже лежит в папке.

### После выкладки

1. **Google Search Console** → добавить домен, подтвердить (обычно записью в
   DNS), отправить `anywheresauna.shop/sitemap.xml`, нажать «Запросить
   индексирование» для главной.
2. **Google Business Profile** — карточка в поиске и на картах. Для местного
   бизнеса в Дубае это даёт больше, чем всё остальное вместе.
3. Проверить, что открывается `anywheresauna.shop/guides/`.

### Чего ждать по времени

Индексация — дни. Позиции по «sauna Dubai» — месяцы, и зависят уже не от
кода, а от ссылок на сайт и живой карточки компании.
## Язык

Сайт только на английском. Русской версии нет: переключатель, файл `ru.js`
и кириллические шрифты убраны. Если когда-нибудь понадобится второй язык —
это отдельная работа, по-быстрому не вернуть.

## Форма

Форма ничего никуда не отправляет: собирает текст и открывает WhatsApp с
готовым сообщением. Бэкенда нет, ничего не хранится.

## Публикация на GitHub Pages

В репозитории лежит `.github/workflows/pages.yml`: каждый пуш в `main`
выкладывает сайт. Один раз нужно включить Pages вручную: **Settings → Pages →
Build and deployment → Source: GitHub Actions**.
