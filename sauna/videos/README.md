# Ролики

Сюда кладутся три видео. Имена важны, по ним страница их и находит:

| Файл | Где играет | Reel в брошюре |
|---|---|---|
| `two-person.mp4` | разворот «Сауна на двоих» | `DanhCAOuNV8` |
| `four-person.mp4` | разворот «Сауна на четверых» | `DfnKi26K2aM` |
| `custom.mp4` | разворот «Под ваше место» | `DcqgzuDCxE1` |

## Как они себя ведут

Ролик стоит на месте большой фотографии разворота. Когда человек долистывает
до него, видео само запускается без звука и крутится по кругу; когда уходит
с экрана — встаёт на паузу. В углу кнопка со звуком: включишь на одном —
остальные замолкают.

Пока файла нет, на его месте просто остаётся фотография. Ничего не ломается.

## Что подходит

MP4, кодек H.264, звук AAC. Вертикальные, 9:16, как в Reels. По ширине
1080 px достаточно. Держи вес до 5–8 МБ на ролик: они грузятся только когда
до них долистали, но на телефоне это всё равно чей-то трафик.

Пережать можно так:

```
ffmpeg -i исходник.mp4 -vf "scale=1080:-2" -c:v libx264 -crf 26 \
  -preset slow -c:a aac -b:a 96k -movflags +faststart two-person.mp4
```
