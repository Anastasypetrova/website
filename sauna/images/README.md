# Фотографии

Положи файлы сюда с такими именами — они встанут на свои места сами.
Пока файла нет, на его месте тёплая заглушка с подписью, какое имя нужно.

| Файл | Где на сайте | Формат |
|---|---|---|
| `hero.jpg` | Первый экран, на весь экран | горизонтальное, 2400×1400 |
| `sauna-villa.jpg` | Карточка «Сауна для виллы» | 4:3 |
| `sauna-garden.jpg` | Карточка «Садовая сауна» | 4:3 |
| `spa-suite.jpg` | Карточка «Спа-зона» | 4:3 |
| `spotlight.jpg` | Большой блок «Самая популярная» | вертикальное или квадрат |
| `install.jpg` | Блок «Устанавливаем сами» | вертикальное 4:5 |
| `project-1.jpg` … `project-5.jpg` | Галерея проектов (первое — широкое) | 4:3 |
| `note-1.jpg` … `note-3.jpg` | Заметки | 4:3 |
| `founder.jpg` | Блок «О нас» | вертикальное 4:5 |
| `og-image.jpg` | Превью ссылки в мессенджерах | 1200×630 |

JPG, до ~400 КБ каждая. Для скорости лучше сжать заранее (например, squoosh.app).
