# Фотографии

Девять снимков, вытащенных из брошюры `Anywhere Sauna` и пережатых под веб
(вся папка около 800 КБ). Один файл — одна фотография; страница ссылается на
них из нескольких мест, а не хранит одну и ту же картинку под четырьмя
именами. Чтобы заменить — положи файл с тем же именем поверх.

| Файл | Что на снимке | Где используется |
|---|---|---|
| `hero.jpg` | сауна на газоне в закатном свете | первый экран |
| `two-terrace.jpg` | кабина на двоих на террасе | карточка, разворот «на двоих», блок «О нас» |
| `two-pool.jpg` | она же у бассейна в сумерках | разворот «на двоих», галерея |
| `two-interior.jpg` | интерьер, печь и ИК-панели | разворот «на двоих», галерея, заметки |
| `four-elevation.jpg` | кабина на четверых, широкий фасад | карточка, разворот «на четверых» |
| `four-corner.jpg` | она же с угла | разворот, галерея, блок про монтаж |
| `four-interior.jpg` | интерьер, ушат и ковш | разворот, галерея, заметки |
| `before.jpg` | ниша до работ | разворот «под ваше место», заметки |
| `after.jpg` | та же ниша с сауной | карточка, разворот «под ваше место» |
| `two-dusk.jpg` | газон и поливалки в розовом небе | разворот «на двоих» |
| `two-inside.jpg` | человек в сауне под луной | разворот «на двоих» |
| `two-rooftop.jpg` | кабина на крыше днём | разворот «на двоих» |
| `two-night.jpg` | терраса ночью, сауна горит | разворот «на двоих» |

Формат JPG, по длинной стороне 1400–1600 px (у `hero.jpg` — 2000), вес до ~140 КБ.
Первые девять сняты в пропорции 3:4, четыре последних — телефонные 9:16,
и на странице они стоят отдельным рядом, чтобы не обрезаться.
Слот без файла показывает тёмную заглушку, так что сайт не ломается.
