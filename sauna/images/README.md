# Фотографии

Все снимки здесь вытащены из брошюры `Anywhere Sauna` и пережаты под веб.
Чтобы заменить любой — положи файл с тем же именем поверх, остальное
подхватится само. JPG, по длинной стороне 1400 px (у `hero.jpg` — 2000),
вес до ~200 КБ.

| Файл | Где на сайте | Что на снимке |
|---|---|---|
| `hero.jpg` | Первый экран | сауна на газоне в закатном свете |
| `sauna-garden.jpg` | Карточка «Сауна на двоих» | кабина на террасе с банановым листом |
| `spa-suite.jpg` | Карточка «Сауна на четверых» | широкий фасад кабины |
| `sauna-villa.jpg` | Карточка «Под ваше место» | сауна, встроенная в нишу |
| `project-5.jpg` | Большой блок «До и после» | та же ниша изнутри |
| `project-1.jpg` … `project-4.jpg`, `install.jpg` | Галерея работ | фасады и интерьеры |
| `founder.jpg` | Блок «О нас» | кабина на террасе в сумерках |
| `note-1.jpg` … `note-3.jpg` | Сейчас не используются | интерьеры и кадр «до» |

Слот без файла показывает тёмную заглушку, так что сайт не ломается, пока
фотографии подбираются.
