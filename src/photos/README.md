# Фотографии сайта

Положите файлы в эту папку, назвав их **точно** так, как указано в таблице.
Расширение — любое привычное: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.

Например: `hero.jpg`, `about.png`, `club.webp` — всё сработает.

Если какого-то файла нет, на его месте останется нейтральная заглушка,
сайт при этом продолжит работать нормально.

| Имя файла      | Где на сайте                          | Какое фото подойдёт                     |
| -------------- | ------------------------------------- | --------------------------------------- |
| `hero`         | Первый экран, на всю ширину           | горизонтальное, объект справа или в центре |
| `about`        | Блок «Обо мне», портрет               | вертикальное, пропорции ~2:3            |
| `club`         | Карточка Samadhi Club                 | почти квадратное                        |
| `consultation` | Карточка «Личная консультация»        | почти квадратное                        |
| `mentorship`   | Карточка «Индивидуальное менторство»  | вертикальное, узкое (~0.72:1)           |
| `mastermind`   | Карточка Mastermind                   | вертикальное (~1:1.15)                  |
| `quote`        | Цитата на фото, после блока видео     | горизонтальное, на всю ширину           |
| `telegram`     | Блок «Подпишитесь на телеграм-канал»  | горизонтальное, на всю ширину           |
| `contacts`     | Блок «Остались вопросы?»              | горизонтальное, на всю ширину           |

## Пара советов

- **Разрешение.** Для фото на всю ширину (`hero`, `quote`, `telegram`,
  `contacts`) берите не меньше 2000 px по длинной стороне. Vite сожмёт
  файлы при сборке, так что присылать сильно ужатые заранее не нужно.
- **Кадрирование.** Фото обрезаются под пропорции блока. Если после
  вставки лицо оказалось срезано — скажите, я подвину кадр
  (параметр `objectPosition` у компонента `<Photo>`).
- **Текст поверх фото.** На `hero`, `quote`, `telegram` и `contacts`
  ложится текст, поверх фото идёт затемнение. Лучше всего смотрятся
  кадры без важных деталей в нижней части.
