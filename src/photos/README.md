# Фотографии сайта

Положите файлы в эту папку. Расширение любое привычное: `.jpg`, `.jpeg`,
`.png`, `.webp`, `.avif`.

Если какого-то файла нет, на его месте останется нейтральная заглушка —
сайт при этом продолжит работать нормально.

## Вариант 1 — папка `uploads` из макета

Проще всего скопировать сюда содержимое папки `uploads` из дизайн-макета
как есть, ничего не переименовывая. Каждое фото встанет ровно туда, где
оно стояло в макете:

| Файл из макета                              | Куда встанет на сайте                 |
| ------------------------------------------- | ------------------------------------- |
| `08574D3F-D1FC-4601-B58F-29C6FAABA71A.JPG`  | Первый экран (hero)                   |
| `9EB2E130-279C-44D5-899C-63C4AB6D6BE4 2.jpg`| Цитата на фото, после блока видео     |
| `ChatGPT Image Jul 23, 2026, 04_17_32 PM.png` | Карточка Samadhi Club               |
| `ChatGPT Image Jul 23, 2026, 04_19_50 PM.png` | Карточка «Личная консультация»      |
| `93A7FE90-DC1C-4ACE-A530-DA2E72B35AF9.JPG`  | Карточка «Индивидуальное менторство»  |
| `ChatGPT Image Jul 24, 2026, 10_24_00 AM.png` | Карточка Mastermind                 |
| `IMG_3101.JPG`                              | Блок «Обо мне», портрет               |
| `PHOTO-2026-07-27-15-34-17 2.jpg`           | Блок «Подпишитесь на телеграм-канал»  |

Регистр букв, пробелы и запятые значения не имеют — файл найдётся в любом случае.

## Вариант 2 — короткие имена

Если хотите поставить другое фото, назовите файл по имени слота:

`hero`, `about`, `club`, `consultation`, `mentorship`, `mastermind`,
`quote`, `telegram`, `contacts`

Например, `hero.jpg` заменит фото на первом экране. Короткое имя имеет
приоритет над файлом из макета, так что заменять можно по одному.

## Слот `contacts`

В макете у блока «Остались вопросы?» фон был оставлен пустым — фото туда
не назначали. Поэтому там пока заглушка. Если нужно фоновое фото,
положите файл `contacts.jpg`.

## Пара замечаний

- **Разрешение.** Для фото на всю ширину (`hero`, `quote`, `telegram`,
  `contacts`) берите не меньше 2000 px по длинной стороне. Vite сожмёт
  файлы при сборке, заранее ужимать не нужно.
- **Кадрирование.** Фото обрезаются под пропорции блока. Если лицо
  окажется срезано — скажите, подвинем кадр (`objectPosition` у `<Photo>`).

## Сжатие

После добавления новых фотографий запустите:

```bash
npm run photos
```

Скрипт уменьшит их до разумного разрешения и переведёт в формат WebP.
Визуально разницы нет, вес падает примерно в 8–10 раз. Повторный запуск
безопасен: уже сжатые файлы пропускаются.
