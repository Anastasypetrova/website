# Карусель для инстаграма

Собирает пост из фотографий Анастасии: подбирает кадры, пишет короткий текст,
раскладывает его по пустым местам снимка и рендерит готовые файлы.

Референс стиля — её собственные карусели: фото во весь кадр, мягкая градиентная
виньетка, мелкий белый гротеск в верхней трети, всегда на пустоте — на небе, на
стене, на песке. Никогда поверх лица, рук или предметов.

## Как выглядит слайд

| | |
|---|---|
| Фото | во весь кадр, без рамок и полей |
| Обработка | минимальная. По умолчанию `grade: "none"` — кадры в референсе не тонированы |
| Виньетка | мягкий градиент, подстраивается под яркость. Не серая плашка |
| Шрифт | Inter Regular, белый. Это ближайший неогротеск к системному iOS из референса, и он уже лежит в `src/fonts/` |
| Кегль | мелкий: 3% ширины кадра. Крупный текст ломает стиль |
| Колонка | узкая, 3-5 строк, перенос примерно на 30 знаках |
| Место | верхняя треть, чаще слева |

**Первый слайд — без текста.** Крючок — само фото. Так в референсе, не нарушай
без прямой просьбы.

## Как писать текст

Голос — её собственный, из канала и отзывов на сайте (`src/content.ts`):

- на «ты», в повелительном наклонении: «перестань», «действуй», «начни»;
- одна мысль на слайд, одно-два предложения, максимум три;
- утверждение, а не рассуждение. Без «попробуй», «возможно», «мне кажется»;
- кавычки-ёлочки: «за», «сегодня будет волшебство»;
- эмодзи — редко и в конце фразы, не больше чем на паре слайдов;
- темы: сознание, состояние, доверие импульсу, реальность как выбор внимания.

Длина: 5-7 слайдов. Больше десяти Instagram не примет, рендер это проверяет.

## Порядок работы

1. **Посмотри фотографии.** Прочитай файлы из `src/photos/` — ты видишь
   изображения. Выбирай кадры, где есть пустая спокойная область: небо, стена,
   вода, размытый фон. Кадр, забитый деталями по всей площади, для текста не
   годится — оставь его первым слайдом, без надписи.

2. **Напиши спеку** — JSON в `tools/carousel/examples/<слаг>.json`:

```json
{
  "slug": "mir-vsegda-za",
  "size": "4:5",
  "handle": "@anastasypetrova",
  "slides": [
    { "photo": "hero" },
    { "photo": "quote", "text": "Перестань думать, что мир против тебя." }
  ],
  "caption": "Текст поста под каруселью."
}
```

   Поля слайда: `photo` (имя слота из `src/photos/` или путь к файлу), `text`,
   `size` (`s`/`m`/`l`), `box` (закрепить место вручную), `tone`
   (`light`/`dark`/`auto`), `vignette` (число, `0` — выключить), `focus`
   (кроп: `centre`, `north`, `auto`), `grade`.

3. **Отрендери:**

```bash
node tools/carousel/render.mjs tools/carousel/examples/<слаг>.json
```

   Скрипт сам меряет кадр и кладёт текст в самое спокойное место. В консоль
   пишет, куда лёг текст, какая яркость под ним и какая вышла виньетка.

4. **Посмотри результат.** Открой отрендеренные PNG из `out/carousel/<слаг>/` —
   именно посмотри, не поверь консоли. Проверь: текст не задевает лицо, руки,
   предметы; читается; не липнет к краю.

5. **Поправь, если надо.** Автоматика ошибается на кадрах, где спокойное место
   есть, но оно смысловое — например, чистая стена прямо за головой. Тогда
   закрепи место руками:

```json
{ "photo": "about", "text": "…", "box": { "x": 0.09, "y": 0.14, "w": 0.44 } }
```

   Координаты — доли кадра от левого верхнего угла. Флаг `--guides` рисует
   выбранную рамку поверх слайда, с ним подгонять быстрее.

## Чего не делать

- Не крась текст в цвета сайта и не подключай Playfair с Great Vibes без
  просьбы. Фирменный стиль сайта и стиль этих каруселей — разные вещи,
  референс намеренно нейтральный.
- Не увеличивай кегль «чтобы лучше читалось». Читаемость даёт виньетка и
  выбор места, а не размер.
- Не ставь текст на первый слайд.
- Не публикуй в инстаграм. Отдай папку и подпись, публикует Анастасия.

## Что где лежит

| Путь | Что |
|---|---|
| `tools/carousel/render.mjs` | рендер: кроп, анализ кадра, съёмка слайдов |
| `tools/carousel/analyze.mjs` | поиск пустого места на фото |
| `tools/carousel/theme.mjs` | CSS слайда, размеры холста, виньетка |
| `src/photos/` | фотографии и имена слотов |
| `out/carousel/<слаг>/` | результат: PNG, `caption.txt`, `preview.html` |
